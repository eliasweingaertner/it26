# Contract: Keys and UI

## "Loading Stereo Sample" requester (extended)

Buttons **Stereo** · Left · Right, Stereo focused. Enter / Space take the
focused one; S = Stereo, L = Left, R = Right (as IT's L/R); Esc = Left (IT);
mouse clicks the buttons. Box widened to fit three buttons (IT's style 3
box, buttons style 8).

## F3 — Sample list

| Key | Action |
|---|---|
| Alt-U on a stereo sample | "Convert to mono": Mix / Left / Right / Cancel |
| Alt-U on a mono sample | "Convert to stereo?" OK / Cancel (both channels = the mono data) |

Every IT F3 key works on stereo samples (see spec US3).

Display: the waveform box shows the left channel in the upper half and the
right channel in the lower half; the sample info shows "Stereo" after the
quality ("16 bit Stereo").
