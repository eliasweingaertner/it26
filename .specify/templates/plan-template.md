## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

Gates derived from the constitution (`.specify/memory/constitution.md` v1.0.0):

- **Engine fidelity (I) + Determinism (III)**: Does this change touch
  engine/pattern-format code (`it_music.c`, `it_effects.c`, `it_tables.c`,
  `it_driver.c`, `it_load.c`, `it_structs.h`, `it_pattern.c`)? If so, it stays a
  1:1 ASM transliteration (names, control flow, byte-exact tables incl. typos,
  `_Static_assert` layouts) AND the `tests/test_pattern.c` regression is re-run
  with all four testdata modules `IDENTICAL`. Any deviation has owner sign-off
  and a recorded justification.
- **Authentic data (II)**: Is any UI layout/color/glyph/coordinate sourced from
  the original ASM data tables (not eyeballed)? Generated `it_vgadata.c` is
  regenerated via `tools/gen_vgadata.py`, never hand-edited. Approximations are
  explicitly flagged.
- **One real engine (IV)**: Editor work builds on the real engine structures and
  entry points; pattern edits round-trip through `it_pattern.c` under
  `Engine_Lock`/`Engine_Unlock`. No substitute engine is introduced.
- **Portability (V)**: Code compiles as C11 on Windows/Linux/macOS; platform and
  presentation specifics live behind the `screen_backend_t` vtable; vendored
  `external/miniaudio.h` is untouched.
